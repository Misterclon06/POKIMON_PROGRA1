# Biblioteca LPC

Biblioteca propia de **listas, pilas y colas** mediante nodos enlazados,
utilizada como TDA.

| Módulo | Responsabilidad |
|---|---|
| `nodo/nodo.c/.h` | Crear, liberar e intercambiar datos de nodos |
| `lista/listas.c/.h` | Secuencias con posiciones desde cero, inserción, extracción, copia y recorridos |
| `pilas/pilas.c/.h` | Pila LIFO: apilar, desapilar y consultar sin desmontarla |
| `colas/colas.c/.h` | Cola FIFO, copia, rotación y concatenación |
